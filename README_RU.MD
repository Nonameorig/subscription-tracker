# 📊 Трекер подписок (Subscription Tracker)

Легковесное, полностью клиентское веб-приложение для отслеживания регулярных платежей и подписок. Разработано с упором на удобство использования на мобильных устройствах (Mobile First) и минималистичный дизайн.

Проект не требует бэкенда, баз данных или сторонних библиотек. Все данные хранятся локально в браузере пользователя (`localStorage`), что гарантирует конфиденциальность и молниеносную работу.

## ✨ Основные возможности

- **Ручной ввод данных**: Добавление названия сервиса, суммы, валюты и даты следующего списания.
- **Мультивалютность**: Поддержка USD, EUR, RUB, KZT, BYN. Итоговые суммы подсчитываются отдельно по каждой валюте (без конвертации по курсу).
- **Умная сортировка**: Ближайшие платежи всегда находятся сверху.
- **Визуальные статусы**: Плашки «Сегодня», «Завтра», «Просрочено» и количество дней до оплаты (с цветовой индикацией).
- **Локализация (i18n)**: Поддержка русского и английского языков. Переводы вынесены в отдельные JSON-файлы.
- **Автосохранение**: Данные мгновенно сохраняются в локальное хранилище браузера.

## 🛠 Технологический стек

- **HTML5**: Семантическая разметка, адаптивная верстка.
- **CSS3**: CSS Variables (кастомные свойства), Flexbox, CSS Grid, медиа-запросы. Никаких фреймворков (чистый CSS).
- **JavaScript (Vanilla)**: Работа с DOM, `localStorage`, `fetch` API для загрузки переводов, `Intl.NumberFormat` для форматирования валют и дат.
